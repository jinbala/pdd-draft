# 拼多多草稿箱批量改价 + 上架

用 Playwright 驱动本机 Chrome，自动完成：**草稿箱每个商品 → 价格 × 倍数 → 提交并上架**。
价格倍数在运行时手动输入。

> 说明：改价时会把编辑页里的 **拼单价 / 单买价 / 市场价(划线价)** 同时乘以倍数，
> 保证三者关系不变、能通过平台校验。单条商品有多个 SKU 时，所有 SKU 价格一起改。

---

## 一、准备（只需一次）

1. 装 Python 3.9+（https://www.python.org/downloads/ ，安装时勾选 **Add python.exe to PATH**）。
2. 在本文件夹地址栏输入 `cmd` 回车，执行：

```bat
pip install -r requirements.txt
```

3. 电脑装了 Chrome 就不用管；没装则改 `config.py` 里 `USE_SYSTEM_CHROME = False`，再执行：

```bat
playwright install chromium
```

## 二、首次登录（只需一次）

```bat
python main.py --scan
```

- 会自动弹出浏览器，若停在登录页，用**拼多多商家版 App** 扫码登录；
- 登录后脚本自动进入草稿箱，打印商品数量；
- 登录状态保存在 `chrome_profile` 文件夹，以后免登录。

## 三、正式运行

```bat
python main.py
```

流程：

1. 让你输入价格倍数（例如 `1.5`）；
2. 逐条：打开编辑页 → 读价格 → 乘倍数 → 点「提交并上架」→ 下一条；
3. 每条之间随机停 3~8 秒，每处理 20 条暂停等你回车；
4. 遇到验证码/滑块会自动暂停，等你手动处理后回车继续。

**建议先小批量试跑：**

```bat
python main.py --multiplier 1.5 --limit 5
```

确认前几条正常上架、价格正确后，再放开跑全部。

## 四、结果与日志

- 每条记录写入 `result.csv`（时间、标题、原价、新价、状态），Excel 可打开；
- 运行日志在 `run.log`；
- 上架成功的商品会离开草稿箱，脚本每次自动处理「第一条」；中断后重跑会接着剩下的处理。

## 五、注意事项

- **风控**：已内置有头浏览器、随机延时、复用登录态、遇验证码暂停等防护，但不能保证 100% 不触发。先 `--limit 5` 试跑。
- **价格规则**：倍数设得不合理（低于类目最低价等）会保存失败，该商品留在草稿箱并被记录，脚本继续下一条。
- **上架失败**：商品信息不全（主图/类目/库存/运费模板等）会提交失败，脚本会提示并停止（连续 2 次失败），你手动处理后再重跑。
- **改配置**：所有可调项（延时、批次、倍数等）都在 `config.py`。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 提示找不到 playwright | 回到第一步 `pip install -r requirements.txt` |
| 打开的不是 Chrome | `config.py` 里 `USE_SYSTEM_CHROME = True` |
| 一直触发验证码 | 把 `DELAY_ITEM` 调大（如 `(6, 12)`）、`BATCH_SIZE` 调小 |
| 想只改价不上架 | 把 `config.py` 里 `submit_btn` 换成 `save_draft_btn`（保存草稿） |
